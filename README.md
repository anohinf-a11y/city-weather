# CityWeather

Консольное приложение на Python для получения текущей погоды в списке городов через API [wttr.in](https://wttr.in/) и расчёта статистики по странам.

Программа автоматически загружает список городов, удаляет дубликаты, получает температуру и страну для каждого города, а затем группирует результаты и вычисляет среднюю, минимальную и максимальную температуру.

## Требования

- Python 3.8+
- Подключение к интернету
- Доступ к API `wttr.in`

Внешние библиотеки не используются. Для работы с JSON применяется стандартный модуль `json`, для HTTP-запросов — `urllib`.

## Запуск

### 1. Подготовка

Скачайте проект и поместите `Cities.txt` рядом с `CityWeather.py`.

В файле `Cities.txt` укажите города, каждый с новой строки:

```text
Moscow
Vienna
Izhevsk
Perm
NhaTrang
Villach
```

### 2. Запуск программы

Открыть файл city_weather.py в Visual Studio и запустить выполнение программы (кнопка запуска или Ctrl+F5). Если Visual Studio предложит выбрать среду выполнения, необходимо установить и настроить Python Development.

## Как это работает

1. **Загрузка списка.** Программа читает города из файла или загружает их по HTTP. Пустые строки игнорируются, дубликаты удаляются с сохранением порядка первого появления.
2. **Получение погоды.** Для каждого города отправляется запрос к `wttr.in` с JSON-форматом `j1`. Запросы выполняются параллельно, при сетевых ошибках предусмотрены повторные попытки.
3. **Модель данных.** Ответ API преобразуется в объект `WeatherData`, содержащий название города, текущую температуру в °C и страну.
4. **Вывод результатов.** Для каждого успешно обработанного города выводятся название, страна и текущая температура.
5. **Статистика.** Города группируются по странам. Для каждой группы рассчитываются количество городов, средняя, минимальная и максимальная температура.
6. **Итог выполнения.** В конце выводится количество городов, успешно обработанных запросов, ошибок и стран в статистике.
